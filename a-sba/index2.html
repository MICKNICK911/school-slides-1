 Setup Guide

      
    

    

      
    
        
  1. Create a new Google Sheet (any name).
    2. 
        
  2. In the sheet, click Extensions → Apps Script.
    3. 
        
  3. Delete the sample code and paste the snippet from Settings. Click Save.
    4. 
        
  4. Click Deploy → New deployment. Type: Web app. Execute as: Me. Who has access: Anyone. Click Deploy.
    5. 
        
  5. Authorize when prompted (it's your own script, so accept).
    6. 
        
  6. Copy the Web app URL (ends in /exec) and paste it into Settings → Save URL → Test connection.
    7. 
        
  7. Done. Use Push to send your local data to the sheet, Pull to fetch from it.
    8. 
      

      
Your Web App URL is a secret. Anyone with it plus your secret token can read/write your sheet. Keep both private.

      
If you edit the snippet later, use Deploy → Manage deployments → Edit → New version to keep the same URL.
